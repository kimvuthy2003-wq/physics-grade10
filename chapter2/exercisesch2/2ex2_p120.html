លំហាត់ទែម៉ូឌីណាមិច (ការដាំទឹក)

២. គេចង់ដាំទឹក 0.300 kg ឱ្យសីតុណ្ហភាពឡើងពី 20°C ទៅ 100°C ។

ក. គណនាថាមពលកម្ដៅដែលត្រូវផ្ដល់ឱ្យទឹកនោះ ។

ខ. ឥឡូវគេយកចង្ក្រានអគ្គិសនីមួយដែលផ្ដល់កម្ដៅ 418.5 J ក្នុងមួយវិនាទីមកដាំទឹកនោះ តើគេត្រូវប្រើរយៈពេលប៉ុន្មាន បើគេឧបមាថាថាមពលកម្ដៅចេញពីចង្ក្រានត្រូវទឹកស្រូបយកទាំងអស់? គេឱ្យ c = 4186 J/kg·°C ។

ដំណោះស្រាយលម្អិត

ក. គណនាថាមពលកម្ដៅដែលត្រូវផ្ដល់ឱ្យទឹក៖

តាមរូបមន្តបរិមាណកម្ដៅស្រូប៖ Q = m · c · ΔT = m · c · (Tf - Ti)

  • m = 0.300 kg
  • c = 4186 J/kg·°C
  • Ti = 20°C, Tf = 100°C

ជំនួសលេខ៖ Q = 0.300 × 4186 × (100 - 20)

Q = 100,464 J

ខ. គណនារយៈពេលដែលត្រូវប្រើសម្រាប់ដាំទឹក៖

តាមរូបមន្តអានុភាពកម្ដៅ (ថាមពលក្នុង១វិនាទី): P = Q / t ⇒ t = Q / P

  • Q = 100,464 J
  • P = 418.5 J/s (ឬ W)

ជំនួសលេខ៖ t = 100,464 / 418.5

t = 240 s (ស្មើនឹង ៤ នាទី)
