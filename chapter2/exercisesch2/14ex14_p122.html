14.
សិស្សរូបវិទ្យាមួយក្រុមធ្វើពិសោធន៍ដោយផ្ដល់កម្ដៅតាមអត្រា 10.0 kJ/mn ទៅឱ្យអង្គធាតុរឹងមួយដែលមានម៉ាស 500.0 g រួចកត់ត្រាសីតុណ្ហភាពជាអនុគមន៍នៃពេល។ ពួកគេគូសក្រាបបង្ហាញដូចរូបខាងស្ដាំ។

ក. តើកម្ដៅឡាតង់រលាយនៃអង្គធាតុរឹងនេះមានតម្លៃប៉ុន្មាន?
ខ. តើកម្ដៅម៉ាសនៃភាពរាវ និងភាពរឹងនៃរូបធាតុនេះមានតម្លៃប៉ុន្មាន?
ចម្លើយ៖ ក. lf = 3.00×104 J/kg   ខ. ភាពរាវ c1 = 1000 J/kg·°C   ភាពរឹង c2 = 1.33×103 J/kg·°C
ក្រាបបម្រែបម្រួលសីតុណ្ហភាពនៃប្រធានលំហាត់

ដំណោះស្រាយ៖

ទិន្នន័យ៖ អត្រាកម្ដៅ (អានុភាព) P = 10.0 kJ/mn = 10,000 J/mn, ម៉ាស m = 500.0 g = 0.5 kg

ក. រកកម្ដៅឡាតង់រលាយ (lf)៖

តាមក្រាប អង្គធាតុរលាយពីនាទីទី 1 mn ដល់ 2.5 mn (សីតុណ្ហភាពថេរ 10°C)។

រយះពេលរលាយ Δt = 2.5 - 1 = 1.5 mn
បរិមាណកម្ដៅ Q = P × Δt = 10,000 × 1.5 = 15,000 J
lf = Q / m = 15,000 / 0.5 = 30,000 J/kg ឬ 3.00 × 104 J/kg

ខ. រកកម្ដៅម៉ាសភាពរាវ (c1) និងភាពរឹង (c2)៖

  • កម្ដៅម៉ាសភាពរាវ (c1)៖ ពីនាទីទី 2.5 ដល់ 4
    Δt = 4 - 2.5 = 1.5 mn → Q = P × Δt = 15,000 J
    ΔT = 40°C - 10°C = 30°C
    c1 = Q / (mΔT) = 15,000 / (0.5 × 30) = 1000 J/kg·°C
  • កម្ដៅម៉ាសភាពរឹង (c2)៖ ពីនាទីទី 0 ដល់ 1
    Δt = 1 - 0 = 1 mn → Q = P × Δt = 10,000 J
    ΔT = 10°C - (-5°C) = 15°C
    c2 = Q / (mΔT) = 10,000 / (0.5 × 15) = 1333.33 ≈ 1.33 × 103 J/kg·°C
