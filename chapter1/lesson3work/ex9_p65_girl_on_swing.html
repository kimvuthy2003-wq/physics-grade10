លំហាត់លេខ ៩ ៖ កុមារីម្នាក់មានម៉ាស $30.0 \text{ kg}$ ជិះទោងក្នុងបរិវេណនៃសាលារៀនមួយ។ ខ្សែទោងនីមួយៗ មានប្រវែង $2.00 \text{ m}$។ កំណត់ថាមពលប៉ូតង់ស្យែលទំនាញផែនដីនៃប្រព័ន្ធកុមារី-ផែនដីធៀបនឹងទីតាំងទាបបំផុតនៃកុមារី ៖

📝 ដំណោះស្រាយលម្អិត

បម្រាប់៖ $m = 30.0 \text{ kg}$, $L = 2.00 \text{ m}$, $g = 9.8 \text{ m/s}^2$។ ទីតាំងទាបបំផុតជាកម្រិតសូន្យ ($h=0$)។
រូបមន្តកម្ពស់៖ $h = L(1 - \cos\theta)$ និងថាមពលប៉ូតង់ស្យែល៖ $U = mgh = mgL(1 - \cos\theta)$

ក. ពេលខ្សែទោងដេកសន្ធឹងត្រង់ ($\theta = 90^\circ$)៖

  • $h = 2.00(1 - \cos 90^\circ) = 2.00(1 - 0) = 2.00 \text{ m}$
  • $U = 30.0 \times 9.8 \times 2.00$ = 588 J

ខ. ពេលខ្សែទោងបង្កើតបានមុំ $\theta = 60.0^\circ$៖

  • $h = 2.00(1 - \cos 60^\circ) = 2.00(1 - 0.5) = 1.00 \text{ m}$
  • $U = 30.0 \times 9.8 \times 1.00$ = 294 J

គ. ពេលខ្សែទោងបង្កើតបានមុំ $\theta = 30.0^\circ$៖

  • $h = 2.00(1 - \cos 30^\circ) = 2.00(1 - 0.866) = 0.268 \text{ m}$
  • $U = 30.0 \times 9.8 \times 0.268$ = 78.8 J

ឃ. ពេលខ្សែទោងឈរសន្ធឹងត្រង់ចុះក្រោម ($\theta = 0^\circ$)៖

  • $h = 2.00(1 - \cos 0^\circ) = 2.00(1 - 1) = 0 \text{ m}$
  • $U = 30.0 \times 9.8 \times 0$ = 0 J
