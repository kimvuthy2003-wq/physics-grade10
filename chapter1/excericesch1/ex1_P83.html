ចលនារបស់អង្គធាតុតាមពីរវិមាឌ (2D Motion)

២. ប្រធានលំហាត់

១. វត្ថុមួយមានម៉ាស $3.00\text{ kg}$ បានផ្លាស់ទីក្នុងប្លង់មួយដែលមានកូអរដោនេ $x = 4t^2 - 1$ និង $y = 2t^2 - 2$ ដែល $x, y$ គិតជាម៉ែត្រ ($\text{m}$) និង $t$ ជាវិនាទី ($\text{s}$) ។

  • ក. កំណត់ល្បឿនដើមនៃវត្ថុ
  • ខ. រកទំហំនៃកម្លាំងដែលមានអំពើលើវត្ថុតាមទិសដៅ $x$ និង $y$
  • គ. គណនាកម្លាំងផ្គួបដែលមានអំពើលើវត្ថុ ។
ផ្នែកខាងក្រោម

៣. ដំណោះស្រាយលម្អិត

បម្រាប់ ទិន្នន័យដើមនៃលំហាត់

  • ម៉ាសរបស់វត្ថុ៖ $m = 3.00\text{ kg}$
  • សមីការកូអរដោនេតាមអ័ក្ស $x$ ៖ $x(t) = 4t^2 - 1 \quad (\text{m})$
  • សមីការកូអរដោនេតាមអ័ក្ស $y$ ៖ $y(t) = 2t^2 - 2 \quad (\text{m})$

ក កំណត់ល្បឿនដើមនៃវត្ថុ ($v_0$)

កំប៉ូសង់ល្បឿននៃវត្ថុតាមទិសដៅ $x$ និង $y$ នៅខណៈ $t$ គឺជាដេរីវេទីមួយនៃកូអរដោនេ $x(t)$ និង $y(t)$ ធៀបនឹងរយៈពេល $t$ ៖

$$v_x(t) = \frac{dx}{dt} = \frac{d}{dt}(4t^2 - 1) = 8t \quad (\text{m/s})$$ $$v_y(t) = \frac{dy}{dt} = \frac{d}{dt}(2t^2 - 2) = 4t \quad (\text{m/s})$$

នៅខណៈដើម $t = 0\text{ s}$ យើងទទួលបានកំប៉ូសង់ល្បឿនដើមតាមអ័ក្សទាំងពីរ៖

$$v_{0x} = v_x(0) = 8(0) = 0\text{ m/s}$$ $$v_{0y} = v_y(0) = 4(0) = 0\text{ m/s}$$

ទំហំល្បឿនដើមនៃវត្ថុគឺ៖

$$v_0 = \sqrt{v_{0x}^2 + v_{0y}^2} = \sqrt{0^2 + 0^2} = 0\text{ m/s}$$
ដូចនេះ ល្បឿនដើមនៃវត្ថុគឺ $v_0 = 0\text{ m/s}$ ។

ខ រកទំហំនៃកម្លាំងដែលមានអំពើលើវត្ថុតាមទិសដៅ $x$ និង $y$

ជាដំបូង យើងគណនាកំប៉ូសង់សំទុះ $a_x$ និង $a_y$ ដោយធ្វើដេរីវេនៃកំប៉ូសង់ល្បឿន $v_x(t)$ និង $v_y(t)$ ធៀបនឹងរយៈពេល $t$ ៖

$$a_x = \frac{dv_x}{dt} = \frac{d}{dt}(8t) = 8.00\text{ m/s}^2$$ $$a_y = \frac{dv_y}{dt} = \frac{d}{dt}(4t) = 4.00\text{ m/s}^2$$

តាមច្បាប់ទី២ញូតុន ($\vec{F} = m\vec{a}$) ទំហំនៃកម្លាំងដែលមានអំពើលើវត្ថុតាមទិសដៅ $x$ និង $y$ គឺ៖

$$F_x = m \cdot a_x = 3.00\text{ kg} \times 8.00\text{ m/s}^2 = 24.0\text{ N}$$ $$F_y = m \cdot a_y = 3.00\text{ kg} \times 4.00\text{ m/s}^2 = 12.0\text{ N}$$
ដូចនេះ កម្លាំងតាមទិសដៅ $x$ គឺ $F_x = 24.0\text{ N}$ និងតាមទិសដៅ $y$ គឺ $F_y = 12.0\text{ N}$ ។

គ គណនាកម្លាំងផ្គួបដែលមានអំពើលើវត្ថុ ($F$)

ដោយវ៉ិចទ័រកម្លាំង $\vec{F}_x$ និង $\vec{F}_y$ កែងគ្នា ទំហំនៃកម្លាំងផ្គួប $\vec{F} = \vec{F}_x + \vec{F}_y$ គណនាតាមរូបមន្ត៖

$$F = \sqrt{F_x^2 + F_y^2} = \sqrt{(24.0\text{ N})^2 + (12.0\text{ N})^2}$$ $$F = \sqrt{576 + 144} = \sqrt{720}\text{ N} = 12\sqrt{5}\text{ N} \approx 26.83\text{ N}$$

ទិសដៅនៃកម្លាំងផ្គួប $\vec{F}$ បង្កើតបានមុំ $\theta$ ធៀបនឹងអ័ក្ស $x$ វិជ្ជមាន៖

$$\tan\theta = \frac{F_y}{F_x} = \frac{12.0}{24.0} = 0.5 \implies \theta = \arctan(0.5) \approx 26.57^\circ$$
ដូចនេះ កម្លាំងផ្គួបដែលមានអំពើលើវត្ថុមានទំហំ $F = 12\sqrt{5}\text{ N} \approx 26.83\text{ N}$ ។
