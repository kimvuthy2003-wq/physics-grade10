វិភាគក្រាបចលនាស៊ីនេម៉ាទិច

ស្វែងយល់ពីទំនាក់ទំនងរវាងបន្ទាត់កាត់រវាងពីរចំណុច (តម្លៃមធ្យម) និងបន្ទាត់ប៉ះ ត្រង់មួយចំណុច(តម្លៃខណៈ)

ការកំណត់តម្លៃមធ្យម (បន្ទាត់កាត់)

ចំណុច t₁: 1.0 s
ចំណុច t₂: 5.0 s

ការកំណត់តម្លៃខណៈ (បន្ទាត់ប៉ះ)

ខណៈពេល t: 5.0 s
គម្លាតពេលសងខាង Δt: 0.0 s
* បើ Δt = 0 បង្ហាញតម្លៃខណៈ (បន្ទាត់ប៉ះ) ជាក់ស្តែង។
* បើ Δt > 0 បង្ហាញការប្រមាណតម្លៃដោយយកចំណុចសងខាង។

📊 ព័ត៌មានល្បឿន

ល្បឿនមធ្យម (v_av):
= Δx / Δt
= 0.00 m/s
ល្បឿនខណៈ (v) ត្រង់ t = s:

📈 ព័ត៌មានសំទុះ

សំទុះមធ្យម (a_av):
= Δv / Δt
= 0.00 m/s²
សំទុះខណៈ (a) ត្រង់ t = s:
