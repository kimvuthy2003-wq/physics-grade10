ចលនារថយន្ត និងក្រាបបង្ហាញទីតាំង-ពេលវេលា

ប្រធានលំហាត់៖ រថយន្តមួយធ្វើចលនាលើផ្លូវត្រង់ទៅទិសខាងកើតបានចម្ងាយ 10.0 km។ បន្ទាប់មកនៅពេលបន្ទាប់ ធ្វើចលនាត្រឡប់ក្រោយនៅលើផ្លូវដដែលបានចម្ងាយ 4.0 km។
ឧបមាថារថយន្តធ្វើចលនាអស់រយៈពេល t = 0.40 h។

ដំណោះស្រាយលំហាត់៖

១. គណនាចម្ងាយចរសរុប (d) និងល្បឿនមធ្យម (v)៖
• ចម្ងាយចរសរុប៖ d = d1 + d2 = 10.0 km + 4.0 km = 14.0 km
• ល្បឿនមធ្យម៖ v = d / t = 14.0 km / 0.40 h = 35.0 km/h
២. គណនាបម្លាស់ទី (Δx) និងវ៉ិចទ័រល្បឿនមធ្យម (vav)៖ (យកទិសខាងកើតជាទិសវិជ្ជមាន)
• បម្លាស់ទីសរុប៖ Δx = x2 - x1 = 10.0 km - 4.0 km = +6.0 km (ទៅទិសខាងកើត)
• វ៉ិចទ័រល្បឿនមធ្យម៖ vav = Δx / Δt = 6.0 km / 0.40 h = +15.0 km/h (មានទិសដៅទៅទិសខាងកើត)
