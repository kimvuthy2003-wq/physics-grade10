សំណួរ និងចម្លើយរូបវិទ្យា (ស៊ីនេម៉ាទិច)

១. ដូចម្តេចហៅថាទំហំស្កាលែ និងទំហំវ៉ិចទ័រ? លើកយកឧទាហរណ៍មកបញ្ជាក់។
ចម្លើយ៖
- ទំហំស្កាលែ (Scalar quantity)៖ ជាទំហំដែលកំណត់ដោយរង្វាស់ (តម្លៃលេខ) តែមួយគត់ ដោយគ្មានទិស និងទិសដៅទេ។
  ឧទាហរណ៍៖ ម៉ាស (m), ពេល (t), សីតុណ្ហភាព (T), ប្រវែង (l), មាឌ (V)...
- ទំហំវ៉ិចទ័រ (Vector quantity)៖ ជាទំហំដែលកំណត់ដោយរង្វាស់ (ម៉ូឌុល) ព្រមទាំងមានទិស និងទិសដៅច្បាស់លាស់។
  ឧទាហរណ៍៖ កម្លាំង (F), ល្បឿន (v), សំទុះ (a), បម្លាស់ទី (d)...
២. ចូរពណ៌នាអំពីវ៉ិចទ័រ។
ចម្លើយ៖ វ៉ិចទ័រត្រូវបានតាងដោយអង្កត់ឈើគូសមានព្រួញនៅចុងម្ខាង ដែលមានលក្ខណៈ ៤ យ៉ាងគឺ៖
១. ចំណុចចាប់ផ្តើម (គល់វ៉ិចទ័រ)៖ ជាចំណុចដែលកម្លាំង ឬទំហំនោះចាប់ផ្តើមមានអំពើ។
២. ទិស (បន្ទាត់ទ្រ)៖ ជាខ្សែបន្ទាត់ត្រង់ដែលវ៉ិចទ័រនោះស្ថិតនៅ (ដេក, ឈរ, ទ្រេត...)។
៣. ទិសដៅ៖ ចង្អុលបង្ហាញដោយក្បាលព្រួញ (ឆ្វេងទៅស្តាំ, លើចុះក្រោម...)។
៤. ម៉ូឌុល ឬរង្វាស់៖ ជាប្រវែងនៃអង្កត់វ៉ិចទ័រ ដែលតំណាងឱ្យទំហំធំឬតូចនៃវ៉ិចទ័រនោះ។
៣. តើបម្លាស់ទី និងចម្ងាយចរខុសគ្នាដូចម្តេច?
ចម្លើយ៖
- ចម្ងាយចរ (Distance, d ឬ s)៖ ជាប្រវែងសរុបនៃគន្លងដែលអង្គធាតុបានធ្វើចលនា។ វាជាទំហំស្កាលែ អាស្រ័យនឹងរាងនៃគន្លង និងតែងតែមានតម្លៃវិជ្ជមានជានិច្ច។
- បម្លាស់ទី (Displacement, Δx)៖ ជាវ៉ិចទ័រភ្ជាប់ពីទីតាំងដើម ទៅទីតាំងស្រេចនៃចលនា។ វាជាទំហំវ៉ិចទ័រ ដែលអាស្រ័យតែលើទីតាំងដើមនិងចុង (មិនខ្វល់ពីរាងនៃគន្លងវាងឡើយ) ហើយអាចមានតម្លៃវិជ្ជមាន អវិជ្ជមាន ឬស្មើសូន្យ។
៤. ចូរសរសេររូបមន្តល្បឿនមធ្យមនិងបញ្ជាក់ខ្នាតនៃទំហំនីមួយៗរបស់វាក្នុងប្រព័ន្ធ SI ។
ចម្លើយ៖
រូបមន្តល្បឿនមធ្យមគឺ៖ Vav = d / t  (ឬ V = Δd / Δt)
ដោយបញ្ជាក់ខ្នាតក្នុងប្រព័ន្ធអន្តរជាតិ (SI)៖
- Vav : ជាល្បឿនមធ្យម មានខ្នាតគិតជា ម៉ែត្រក្នុងមួយវិនាទី (m/s)
- d : ជាចម្ងាយចរសរុប មានខ្នាតគិតជា ម៉ែត្រ (m)
- t : ជារយៈពេលធ្វើចលនា មានខ្នាតគិតជា វិនាទី (s)
៥. ចូរសរសេរសមីការដែលបញ្ជាក់ពីទំនាក់ទំនង a, x, v0 និង t ក្នុងចលនាតាមមួយវិមាត្រ។
ចម្លើយ៖ នេះគឺជាសមីការទីតាំងនៃចលនាត្រង់ប្រែប្រួលស្មើ តាមមួយវិមាត្រ ដែលមានទំនាក់ទំនងដូចខាងក្រោម៖

x = x0 + v0t + ½ at²

(បញ្ជាក់៖ បើទីតាំងដើម x0 = 0 នោះសមីការក្លាយជា x = v0t + ½ at² )
៦. ដូចម្តេចហៅថាទម្លាក់សេរី?
ចម្លើយ៖ ទម្លាក់សេរី គឺជាចលនារបស់អង្គធាតុដែលធ្លាក់ចុះក្រោម ក្រោមអំពើនៃទម្ងន់របស់វាតែមួយគត់ (កម្លាំងទំនាញផែនដី P) ដោយមិនគិតពីកម្លាំងទប់នៃខ្យល់ឡើយ។
(ចំណាំ៖ ក្នុងទម្លាក់សេរី អង្គធាតុតែងតែមានចលនាស្ទុះស្មើ ដែលមានល្បឿនដើម v0 = 0 និងមានសំទុះស្មើនឹងសំទុះទំនាញដី a = g ≈ 9.8 m/s²)
