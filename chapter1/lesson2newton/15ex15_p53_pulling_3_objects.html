ក. រកសំទុះរបស់ប្រព័ន្ធ (a)៖

ដោយសារប្រព័ន្ធផ្លាស់ទីគ្មានកកិត តាមច្បាប់ទី២ញូតុន៖

a = F / (m1 + m2 + m3)
a = 42 / (1 + 2 + 3)
a = 7.00 m/s²
ខ. រកតំណឹងខ្សែដែលភ្ជាប់ m3 និង m1 (T)៖

T = (1 + 2) × 7.00
