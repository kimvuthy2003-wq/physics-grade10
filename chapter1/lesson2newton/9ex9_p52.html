លំហាត់ទី៩៖ អង្គធាតុពីរភ្ជាប់ដោយខ្សែឆ្លងកាត់រ៉ក

៩. គេភ្ជាប់អង្គធាតុពីរដោយខ្សែដែលឆ្លងកាត់រ៉កមួយ (កកិតរវាងខ្សែនិងរ៉កអាចចោលបាន) រួចគេលែងវត្ថុនោះដោយល្បឿនដើមស្មើ 0 ។ គេឱ្យ m₁ = 2.0 kg, m₂ = 5.0 kg និង θ = 60° ។ គណនា៖
ក. សំទុះនៃអង្គធាតុទាំងពីរ ។
ខ. តំណឹងខ្សែដែលភ្ជាប់អង្គធាតុទាំងពីរ ។
គ. ល្បឿនរបស់អង្គធាតុនីមួយៗ ក្រោយពីផ្លាស់ទីបានរយៈពេល 2.0s ។ (យក g = 9.80 m/s²)
ឃ. បើកកិតរវាងប្លង់ទេរនិងម៉ាស m₂ ដោយយកមេគុណកកិត μₖ = 0.2 ។ កំណត់សំទុះនិងតំណឹងខ្សែឡើងវិញ ។
ទិន្នន័យជាក់ស្តែង (Live Data):

ដំណោះស្រាយ៖
ក. គ្មានកកិត៖
a = (m₂sinθ - m₁)g / (m₁ + m₂) = (5sin60° - 2)(9.8) / 7 ≈ 3.26 m/s²

ខ. តំណឹងខ្សែ៖
T = m₁(a + g) = 2.0(3.26 + 9.80) ≈ 26.12 N

គ. ល្បឿនក្រោយ 2.0s៖
v = at = 3.26 × 2.0 = 6.52 m/s

ឃ. ករណីមានកកិត (μₖ = 0.2)៖
fₖ = μₖm₂gcosθ = 0.2 × 5 × 9.8 × cos60° = 4.9 N
a' = (m₂gsinθ - m₁g - fₖ) / (m₁ + m₂) ≈ 2.56 m/s²
T' = m₁(a' + g) = 2.0(2.56 + 9.80) ≈ 24.72 N
