ទិសដៅចរន្តអគ្គិសនី និងបន្ទុក

នៅពេលប្ដូរប៉ូលថ្មពិល ទិសដៅរត់នៃអេឡិចត្រុង (e-) នឹងផ្លាស់ប្ដូរ ធ្វើឱ្យម៉ូទ័របង្វិលបញ្ច្រាសទិសគ្នា។

ការគណនាបន្ទុកអគ្គិសនី (Q)

រូបមន្ត៖ Q = n × |-e|

ដោយ |-e| = 1.6 × 10-19 C

ចំនួនអេឡិចត្រុង (n): 0
បរិមាណបន្ទុក (Q): 0 C
